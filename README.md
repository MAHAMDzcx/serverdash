# ServerDash — لوحة تحكم بوتات ماينكرافت

موقع حقيقي (Node.js) تسجّل فيه حسابك، تضيف سيرفر ماينكرافت، فيدخل إليه بوت **Mineflayer** فعليًا وتظهر لك المعلومات الحقيقية فقط.
لا توجد سيرفرات جاهزة ولا بيانات تجريبية: إذا لم تتوفر معلومة تظهر «—» بدل رقم مختلق.

## التشغيل

يتطلب Node.js 18 أو أحدث (يفضّل 20+).

```bash
npm install
npm start
```

ثم افتح http://localhost:3000 ← أنشئ حسابًا ← «إضافة سيرفر».

للاستضافة: يلزم مزوّد يشغّل Node.js (VPS، Render، Railway، Fly.io…). لا يعمل على استضافات الملفات الثابتة مثل Netlify/GitHub Pages لأن البوت يحتاج عملية تعمل باستمرار.
احتفظ بمجلد `data/` (يحتوي الحسابات والسيرفرات والمفتاح) على قرص دائم، وضع الموقع خلف HTTPS مع `TRUST_PROXY=1`.

## ماذا يعرض الموقع؟

**من فحص السيرفر المباشر** (بروتوكول Server List Ping الرسمي، بدون البوت): الحالة، وصف السيرفر MOTD، إصدار السيرفر، اللاعبون x/max، زمن الاستجابة، أيقونة السيرفر.

**من البوت نفسه بعد دخوله**: حالة الاتصال، مدة البقاء، الصحة والجوع، وضع اللعب، البُعد، الإحداثيات، وقت اللعبة، قائمة اللاعبين الحقيقية، ويمكنك إرسال رسائل شات عبره.

**السجل**: كل الأحداث والأخطاء الفعلية (رفض الاتصال، الطرد وسببه، whitelist، انتهاء المهلة، إعادة المحاولة…) برسائل عربية واضحة.

## الميزات

- تسجيل دخول حقيقي: كلمات المرور بـ scrypt، جلسات في كوكي HttpOnly، حماية CSRF، تحديد محاولات الدخول.
- كل مستخدم يرى سيرفراته فقط.
- إعادة اتصال تلقائية بمهلة متزايدة، ومنع الطرد بسبب الخمول (اختياري).
- يستأنف البوتات التي كانت تعمل عند إعادة تشغيل الخادم.
- كلمة مرور البوت (لأوامر /login و/register) تُحفظ مشفّرة AES-256-GCM ولا تُرسل للمتصفح.
- واجهة عربية RTL متجاوبة (جوال/تابلت/حاسوب) مع وضع داكن وفاتح.

## متغيرات البيئة (اختيارية)

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `PORT` | 3000 | منفذ الموقع |
| `DATA_DIR` | `./data` | مكان حفظ البيانات |
| `ALLOW_REGISTRATION` | true | اجعله `0` لإغلاق التسجيل بعد إنشاء حسابك |
| `ALLOW_PRIVATE_HOSTS` | false | `1` للسماح بسيرفرات الشبكة المحلية (127.0.0.1، 192.168.x…) |
| `TRUST_PROXY` | false | `1` إذا كان الموقع خلف Nginx/Cloudflare |
| `COOKIE_SECURE` | auto | يُفعَّل تلقائيًا مع HTTPS |
| `MAX_SERVERS_PER_USER` | 10 | الحد الأقصى للسيرفرات لكل مستخدم |
| `SECRET_KEY` | ملف `data/secret.key` | مفتاح تشفير كلمات مرور البوتات |

## ملاحظات مهمة

- **Aternos وأشباهها**: السيرفر يجب أن يكون شغّالًا. البوت لا يشغّل السيرفر؛ شغّله من موقع الاستضافة ثم يدخل البوت. إن كان مغلقًا ستظهر الحالة «السيرفر لا يستجيب» مع السبب.
- الدخول بوضع **Offline** فقط (سيرفرات Aternos/Cracked). حسابات مايكروسوفت الأصلية غير مدعومة.
- إن ظهر خطأ عدم توافق إصدار، حدّد إصدار السيرفر يدويًا في «تعديل» (مثل `1.20.4`).
- بوتات الاستضافات المجانية قد تُمنع من بعض السيرفرات؛ هذا قرار السيرفر وسيظهر سبب الطرد في السجل.

## الاختبارات

```bash
npm test          # اختبار الخادم الكامل (62 فحصًا)
node test/ui.js   # اختبار الواجهة
```

تعمل الاختبارات بدون إنترنت: تستخدم سيرفر ماينكرافت وهميًا للفحص و mineflayer وهميًا لمنطق اللوحة فقط.

## الهيكل

```
server.js        الخادم، المسارات، تسجيل الدخول

lib/mcping.js    فحص السيرفر عبر Server List Ping
lib/auth.js      كلمات المرور والجلسات وتحديد المعدل
lib/db.js, store.js, crypto.js, util.js, config.js
public/          الواجهة (index.html, app.js, styles.css)
test/            الاختبارات
```
